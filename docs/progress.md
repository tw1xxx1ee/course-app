# Ход работы

## ЛР 1 — Старт проекта на React и TypeScript

Коммит: тег `lab-1`.

Создан проект Vite (React + TypeScript) в папке `frontend`, стартовый экран заменён
собственным экраном «Каталог игр», удалены логотипы и счётчик шаблона.

Проверка:

1. `cd frontend && npm ci && npm run dev` — открывается экран «Каталог игр».
2. Временно присвоить `appTitle` число — `npm run build` падает с ошибкой TS2322.
3. Вернуть строку — `npm run build` проходит.
4. `npm run preview` — показывает готовую сборку.
5. Клонировать репозиторий в новую папку, выполнить `npm ci` и `npm run build` в `frontend`.
